# StudyMind AI

StudyMind AI is a modern academic assistant interface designed as the frontend for an AI-powered student chatbot.

## Current Version

This version focuses on the frontend experience:

- ChatGPT-style conversation interface
- Responsive sidebar
- Recent chat history UI
- New chat functionality
- Prompt suggestions
- Responsive mobile layout
- Auto-resizing message box
- Temporary frontend response simulation

## Project Structure

```text
studymind-ai/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run Locally

No framework or build tool is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For development, the project can also be opened using VS Code Live Server.

## Goal

StudyMind AI aims to become a context-aware academic assistant that can help students understand concepts, study from their own notes, generate quizzes, and track learning progress.
